📈 Data Structure Performance

🔍 Structure Details

AVL Tree (Self-Balancing Binary Search Tree)

  • Purpose: Maintains sorted player data for efficient leaderboard queries
  • Operations: O(log n) insert, delete, search
  • Balance: Automatically maintains height difference ≤ 1
  • Height: Indicates tree balance and search efficiency

Max Heap (Priority Queue)

  • Purpose: Quick access to highest-scoring players
  • Operations: O(log n) insert, O(1) get max
  • Structure: Complete binary tree with heap property
  • Size: Total number of players in heap

Hash Table (Player Map)

  • Purpose: Fast player lookup by ID
  • Operations: O(1) average case lookup
  • Collisions: Handled via chaining or open addressing
  • Size: Number of key-value pairs stored

Activity Log (Vector)

  • Purpose: Records all player score changes and events
  • Operations: O(1) append, O(n) traversal
  • Size: Total number of logged activities
  • Retention: Maintains recent activity history
